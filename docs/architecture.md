# 架构边界（V0）

## 依赖方向

```
desktop (Pygame / 输入 / 绘制)
        ↓
core (游戏状态 / 规则 / 领域逻辑)

configs (YAML 数据) → 由应用加载并校验
```

`core` 不导入 Pygame，不读窗口事件，也不负责绘制。桌面层负责把用户输入转换为核心命令，并把核心状态交给渲染器显示。规则数值不写进渲染代码。

## YAML 配置

- `configs/rules/`：比赛赛季、模式与规则集。
- `configs/teams/`：队伍级机器人阵容与参数。
- `configs/scenarios/`：教学目标、初始部署与场景参数。
- 每份文件包含 `schema_version`，便于后续迁移。
- 当前 YAML 仅是未验证占位结构；录入官方规则或实车数据时必须标明来源与更新时间。

## V0 范围

本阶段只建立 Python/Pygame 桌面工程，Windows 优先并同步支持 macOS。V0 单机运行，不引入局域网、服务端、Web 或移动端代码。未来若增加平台，核心规则与状态应保持可复用。
