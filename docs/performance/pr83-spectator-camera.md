# PR #83 — RMUC 观战镜头与战斗特写

基线 `main=14e9555ea26ce9405e1eae4ea1f472b71f181cea`。
本 PR 只涉及桌面 presentation；没有修改场地、坐标、装甲、弹丸、裁判、寻路或 AI。

## 操作

- 默认全场视角；鼠标滚轮：指针位置缩放（1.0–3.6×）。
- 地图内按住**右键或中键**拖动：平移并接管自动镜头。
- 单击选中机器人后按 **F**：平滑跟随，目标死亡时停留、复活后续跟。
- 按 **A**：开启自动战斗镜头；优先选择真实物理弹丸击中敌方装甲的事件。
- 按 **0**：平滑回到全场；**R** 重开对局时相机同步复位。
- 自动镜头最低切换间隔 2.8 秒；没有后续交火事件时约 5 秒后回到全场。
- HUD 不受相机缩放影响；局部战场按固定视图裁剪，镜头不会移动到场地外。

## 实现与缓存

`SpectatorCamera` 仅保存一个镜头（mode、focus、zoom、cut cooldown）。
全场 viewport 与世界尺寸完全保留；平滑收敛后由原来的 world-to-screen
变换直接渲染局部视图。自动选镜头只读取 `ProjectileImpact` 实际碰撞
快照：装甲有效伤害 > 其他装甲接触 > 非装甲接触，优先容纳双方。

相机放大时，现有机器人 chassis/turret/LED 素材按相同放大倍率
通过 `AssetManager` 的尺寸/角度缓存渲染，弹丸同样放大。
静态场地首次放大时预渲染 2.5× 的世界图层；后续相机平移和缩放
仅采样当前可见区域到固定大小的复用 Surface，不随每帧相机变化
重新申请整场大图。离屏机器人与静态区域跳过昂贵绘制。

## 性能

本机 macOS Apple Silicon，SDL dummy 渲染，1100×780，目标60Hz。
这些数据是 Pygame 模拟和绘制工作，不含显示合成、真实显示器延迟。

**默认全场模式**：现有 `benchmark_rmuc_frame_pacing.py`，
720 帧、预热 120 帧后 600 帧样本：

| 指标 p95/p99 (ms) | 基线 main | PR #83（再次运行） |
| --- | ---: | ---: |
| 帧间隔 | 19/19 | 21/22 |
| 纯绘制 | 3.53/4.22 | 3.78/4.04 |
| 单帧工作 | 11/15 | 14/15 |
| 超过33ms | 0 | 0 |

一轮较早的候选采样为帧间隔 19/19ms，绘制 3.99/5.44ms。
因此短样本存在环境波动，不将数值描述为无回归。

**3.4× 局部特写 3600 帧长测**，预热120帧、采样3480帧：

| 指标 | p95 (ms) | p99 (ms) |
| --- | ---: | ---: |
| 帧间隔 | 19 | 19 |
| 整帧工作 | 10.31 | 11.82 |
| Match + visuals + camera 更新 | 5.86 | 6.81 |
| 纯绘制 | 5.49 | 5.90 |

长测最大帧间隔 20ms，超 33ms 帧数 0；同场景视觉反弹峰值 36。
渲染耗时相比默认全场略有增加，但运行中无持续的长帧堆积。
下一阶段美术重做、复杂 3D 物理引擎和额外场地状态均未引入。
